# RDG Elevate

Build a premium, clean, modern, responsive corporate website for RDG Future Way Pvt. Ltd.

The company operates on a Direct Selling / Network Marketing (Generation Plan) business model and offers products in multiple categories including:

 Ayurvedic & Healthcare Products

 Pharmaceutical Products

 Agricultural Products

 Organic Products

 Clothing & Fashion

 Daily Essentials

 Personal Care

 Home Care

 Wellness Products

The website should establish trust, encourage product purchases, explain the business opportunity, and attract new distributors.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
